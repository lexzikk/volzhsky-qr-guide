# QR-гид по местам города Волжского

Все HTML-страницы лежат в корне архива — так их проще загружать с телефона.
- `index.html` — главная страница;
- `styles.css` — оформление;
- 10 файлов `*.html` — отдельные страницы мест;
- `qr/` — 10 отдельных QR-кодов и QR-код главной страницы.

QR-коды направлены на будущие адреса GitHub Pages:
`https://lexzikk.github.io/volzhsky-qr-guide/`

Они начнут работать после загрузки файлов в репозиторий `lexzikk/volzhsky-qr-guide` и включения GitHub Pages.

## Публикация
1. Распакуй архив в приложении «Файлы».
2. В репозитории GitHub нажми **Add file → Upload files**.
3. Выбери `index.html`, `styles.css` и все 10 остальных HTML-файлов из распакованной папки.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В **Build and deployment** выбери **Deploy from a branch**.
7. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
8. Подожди публикации и проверь адрес сайта.

Папку `qr` загрузи отдельно после публикации, если хочешь хранить QR-картинки прямо в репозитории. QR-коды можно также распечатать из архива.
Не публикуй пароли, токены или личные данные.
